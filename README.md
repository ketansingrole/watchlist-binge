# watchlist-binge

Landing page, Support and Privacy Policy for the **Watchlist Binge** app.

**Live URLs:**
- Landing: `https://ketansingrole.github.io/watchlist-binge/`
- Support URL (App Store Connect): `https://ketansingrole.github.io/watchlist-binge/`
- Privacy Policy: `https://ketansingrole.github.io/watchlist-binge/privacy.html`  ← use this for App Store Connect > App Privacy > Privacy Policy URL

This repo is public and contains only the website. Main app repo `Watchlist-ios` remains private.

## Screenshots
`screenshots/` holds store screenshots generated by `scripts/app-store-screenshots` in the app repo. Keep Disney-owned (Pixar, Marvel, Star Wars) and Apple TV+ artwork off this site: App Review rejected 1.3 for Toy Story artwork.
