# watchlist-binge

Landing page + Privacy Policy for **Watchlist Binge** iOS app.

**Live URLs:**
- Landing: `https://ketansingrole.github.io/watchlist-binge/`
- Privacy Policy: `https://ketansingrole.github.io/watchlist-binge/privacy.html`  ← use this for App Store Connect > App Privacy > Privacy Policy URL

This repo is public and contains only the website. Main app repo `Watchlist-ios` remains private.
